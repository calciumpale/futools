# futools

futools 是一款 macOS 菜单栏工具，用快捷键把提示词、语音输入、截图 OCR 和聊天助手带到当前应用。

- **命令面板**可搜索、管理和插入提示词，也可用 DeepSeek 优化草稿。
- **精简模式**贴在 Codex、ChatGPT 等受支持应用的输入框上方，语音或键入的草稿优化后可直接填入。
- **侧边 Copilot**贴在微信、企业微信、飞书和钉钉的聊天窗口旁，支持按语气生成回复、点一下填入聊天框，也提供自定义资料库和 Agent 问答。

已保存提示词的管理、搜索和插入可离线使用。提示词优化、截图 OCR、回复建议和 Agent 使用你自己的 DeepSeek API Key。 [配置方法](#提示词优化)

## 下载与安装

当前仓库源码可构建 **1.5.2**。 [本地构建](#本地构建)

GitHub Releases 提供的安装包版本为 **v1.3**，适用于运行 macOS 13 及以上版本的 Apple 芯片和 Intel Mac。 [v1.3 发布说明](https://github.com/calciumpale/futools/releases/tag/v1.3) · [下载 v1.3 通用安装包](https://github.com/calciumpale/futools/releases/download/v1.3/futools-v1.3-macOS-universal.zip)

将校验文件和 ZIP 放在同一目录，运行 `shasum -a 256 -c futools-v1.3-macOS-universal.zip.sha256` 即可核对下载。 [SHA-256 校验文件](https://github.com/calciumpale/futools/releases/download/v1.3/futools-v1.3-macOS-universal.zip.sha256)

1. 解压 ZIP，把 `futools.app` 拖到 Finder 的「应用程序」中。
2. 双击打开 `futools`。首次启动会打开设置，以后也可从菜单栏的 futools 图标进入。
3. 要启用自动填入，在应用设置中点「打开系统设置」，然后在 macOS 的「系统设置 → 隐私与安全性 → 辅助功能」中开启 futools。授权前也能使用面板，按 **Enter** 会把提示词复制到剪贴板。

### 首次打开时的 macOS 提示

v1.3 安装包使用临时签名（ad hoc），尚未通过 Apple 公证。如果 macOS 提示无法验证开发者，请先确认应用来自上面的 GitHub 发布页。尝试打开后，进入「系统设置 → 隐私与安全性」，在「安全性」区域点击「仍要打开」，再按系统提示确认。这个设置仅适用于当前应用。 [Apple：在 Mac 上安全地打开 App](https://support.apple.com/zh-cn/102445)

## 命令面板

1. 将光标放在目标输入框里，按 **⌃⌥Space** 唤出面板。在顶部输入框键入关键词即可搜索，也可以直接写一段待优化的草稿。
2. 点击提示词或用 **↑ / ↓** 切换，右侧会显示所选提示词的完整正文。
3. 按 **Enter** 或点击「插入」，把选中的提示词填入原应用，由你决定何时发送。按 **Esc** 或再按一次全局快捷键可关闭面板。

在菜单栏的「管理提示词」中添加、修改或删除提示词。拖动列表每行右侧的把手即可排序，命令面板会同步这个顺序。搜索覆盖标题、分类和正文。

在「设置 → 全局快捷键」中可分别录制命令面板、精简模式和侧边 Copilot 的快捷键。按下新的组合键即可保存，例如 **⌃⌥P**。录制时可按 **Esc** 取消。提示词和快捷键保存在本机 `~/Library/Application Support/Prompt Dock/library.json`。

如果原应用已切换、辅助功能权限不可用，或从已识别的终端应用选择了多行提示词，应用会复制文本。请回到目标输入框并按 **⌘V**。

自动填入使用系统剪贴板。若 macOS 允许应用读取剪贴板，填入后会尝试恢复原内容。否则剪贴板会保留这次选中的提示词。

如果系统的辅助功能开关已打开，应用内仍显示「待授权」，可以从辅助功能列表移除旧的应用条目，再用列表底部的「+」添加当前的 `futools.app`。之后退出并重新打开应用。

## 按住说话

启用辅助功能后，打开命令面板就可以直接按住触控板说话，指针可以留在原来的位置。松开后，转写文字会填到输入框的光标处。也可以按住面板上的麦克风。首次使用时，按 macOS 的提示允许麦克风和语音识别权限，再次按住即可开始录音。

转写使用 macOS 自带的语音识别。支持本机识别时，音频在设备上处理。需要联网识别时，音频会发送给 Apple 处理。 [Apple 语音识别文档](https://developer.apple.com/documentation/speech/sfspeechrecognitionrequest/requiresondevicerecognition)

## 截图 OCR

截图识别需要在设置中配置自己的 DeepSeek API Key。 [配置方法](#提示词优化)

- 将截图复制到剪贴板，在命令面板的输入框按 **⌘V**，再点 **OCR**。点击后会清空输入框，左栏预览截图，右栏显示可编辑的识别结果。用底部按钮复制结果或填回原应用。
- 将截图拖到 macOS 菜单栏的 futools 图标。小框出现后，可松手放到图标或小框，自动识别。识别结果可以复制，也可以送到命令面板继续编辑。

开始识别时，截图会发送到 DeepSeek OCR API，沿用设置中的 DeepSeek API Key，并按识别页数计费。 [DeepSeek OCR 文档](https://api-docs.deepseek.com/guides/ocr/)

## 精简模式

先把光标放在 Codex 或其他应用的输入框里，再按 **⌃⌥⇧Space** 或从 futools 的菜单栏图标选择「精简模式」。精简面板会贴在目标输入框上方，左侧写草稿，右侧可按住麦克风说话或点击「优化提示词」。也可以按 **⌘↩** 优化。结果会直接填回原输入框，精简面板会留在原位。

精简面板或原输入框有焦点时，可以直接长按触控板说话，松开后文字会填到精简面板的草稿框。按 **Esc** 可取消录音并把焦点交还原应用。切到其他应用时，小框暂时隐藏，回来后会自动恢复。再次按精简模式快捷键可关闭。精简模式需要辅助功能权限。

在「设置 → 外观」中可选择跟随系统、日间或夜间。

## 微信和飞书回复建议

在 Mac 版微信或飞书中打开聊天会话，再按 **⌃⌥⇧Space** 启动精简模式。从任意一角拖出选框，框住聊天消息，让选框底边落在可打字的区域内。松手即完成，futools 会定位当前会话的输入框。切换到另一个聊天窗口后，再按快捷键即可在该窗口使用。

- **粘贴聊天内容。** 复制同一会话的几轮聊天或一张截图，再点「粘贴聊天内容」。飞书启用自动截图时，可以从「会话内容」菜单中选择该操作。也可在「回复草稿」按 **⌘V** 添加截图。此方式适用于 macOS 13 或更新版本。
- **框选会话消息。** 如果 macOS 允许截取当前聊天窗口，可以使用框内可见的消息生成回复。要调整范围或输入位置，选择「重新框选消息区」。自动截图需要 macOS 14.2 或更新版本及屏幕录制权限。

提供上下文时，带上对方最新一条待回复的消息和前面相关的约定。例如，对方问「还是按之前的时间吗？」，就把前面约定「周五 16:00」的那几句也选上。粘贴文字时，可用「我：」和「对方：」标记每条消息的说话人。粘贴文字和截图识别结果都以最近 3,500 个字符为上限。粘贴的文字超出上限时，面板会提示只保留末尾。

1. 点「回复设置」可选生成 1、2 或 3 条回复，语气可选自然、活泼、沉稳、简洁、礼貌、搞怪、反讽、有趣和正式。设置通常在下方左侧，窄面板中会收在麦克风旁。默认生成 1 条，语气为自然。条数和语气会保存在本机。
2. 「回复草稿」可以留空，也可以写下希望怎么回，例如「确认时间，再问是否需要提前发材料」。按住麦克风或在当前会话内长按触控板也能输入草稿。点「建议回复」，首次在该应用使用时核对提示并点「同意并建议」。出现「选一句对方说的话」时，选择你要回的消息。飞书截图可以依照位置查找消息，其他说话人身份仍需由原文确认。
3. 生成一条时，建议会直接出现在「回复草稿」。生成多条时，先在「选一条回复」中选一条，再核对和编辑。点一次「插入」，futools 会聚焦原会话的输入框并填入草稿。核对后在原会话里自行发送。

直接再点「建议回复」会沿用原来的回复意图。改过建议后再点，会用改后的文字作为这次的意图。重新粘贴上下文时，如果草稿仍是刚生成的建议，面板会恢复你的原始意图。你手动改过的文字会保留。

截图在本机识别，复制的聊天文字直接作为上下文。生成建议时，DeepSeek 会收到聊天文字和选定的对方消息，以及你填写的回复意图和所选的非默认语气。费用按 DeepSeek API 用量计算。使用回复建议需要辅助功能权限及设置中的 DeepSeek API Key。 [配置方法](#提示词优化)

## 侧边 Copilot

在微信、企业微信、飞书或钉钉的 Mac 客户端中把光标放进聊天输入框，按 **⌃⌥K**，或从 futools 菜单栏选「侧边 Copilot」。可在「设置 → 全局快捷键」中修改快捷键。侧栏默认吸附在会话窗口右边，也可点击顶栏的吸附按钮一键切换左侧 / 右侧吸附；若目标侧空间不足，futools 会先尝试临时移动或缩小聊天窗口（关闭侧栏时自动恢复），或在无法调整时自动回退到另一侧。可使用 **⌘1 / ⌘2 / ⌘3** 在回复、资料库与 Agent 间快速切换。

- **回复**支持「框选消息」和「粘贴内容」，可预览截图或展开文字。在「我想说的话」中输入，或在输入区内长按触控板说话。点击「建议回复」后，futools 按「回复风格」选定的语气和 1–3 条生成建议，可结合提供的会话上下文。生成后原文仍会保留，点击建议即可填入聊天框。自动截取聊天窗口需要 macOS 14.2 及以上版本和屏幕录制权限。
- **资料库**支持按分类（全部 / 文案 / 链接 / 图片 / 视频）筛选、置顶、标签搜索、图片与视频缩略图预览、剪贴板一键新建以及直接拖入文件/链接/文本导入。点击「放入微信/飞书等」可将内容直接交给聊天应用，也可「填入草稿」编辑、复制或将媒体拖到聊天输入框；编辑采用侧栏内联表单，不遮挡会话窗口。
- **Agent**采用多轮对话流与底部停靠输入区，支持 Markdown 渲染、展开查看「本地资料 / 网页」参考来源，以及按需开启「资料库 / 联网 / 当前对话」三类检索范围；每条回答均支持「用作草稿」「直接插入」「复制」「存为资料库文案」及重新生成。

提交 Agent 问题时，会发送问题、历史对话及所启用的资料摘录或聊天文字。媒体源文件保留在本机。联网搜索可能产生额外 API 费用。 [DeepSeek 搜索说明](https://api-docs.deepseek.com/guides/search/)

侧栏跟随 futools 的外观设置和 macOS 的「减少动态效果」设置。 [动效审查与实测](docs/motion-review.md)

## 提示词优化

提示词优化、截图 OCR、聊天回复建议和 Agent 均为可选功能，安装包不包含 API Key。

1. 在 DeepSeek 开放平台创建 API Key。 [DeepSeek API Keys](https://platform.deepseek.com/api_keys)
2. 打开 futools 的「设置」，在「DeepSeek API」里填写自己的 API Key，再点「保存密钥」。密钥保存在 macOS 钥匙串里。
3. 在同一个输入框搜索提示词，或写入、粘贴草稿。按 **⇧↩** 换行，点底部的「优化提示词」或按 **⌘↩** 提交优化。
4. 优化结果出现在面板右侧。结果出现后可继续编辑、填入原输入框，或存为新提示词。如果切换到已保存的提示词，点击右侧的「选用结果」可返回优化结果。

已预设 DeepSeek V4.1 Flash，模型 ID 为 `deepseek-flash`。点击「优化提示词」时，草稿会发送到 DeepSeek 官方 API，按 DeepSeek 的 API 用量计费。 [DeepSeek API 文档](https://api-docs.deepseek.com/api/create-chat-completion/) · [用量与价格](https://api-docs.deepseek.com/quick_start/pricing/)

## 本地构建

需要 macOS 13 或更新版本和 Swift 命令行工具。构建脚本生成当前 Mac 架构的本地签名应用。

```sh
./scripts/build-app.sh
open "dist/futools.app"
```

默认沿用 `dist` 中上一版的签名证书。首次构建时也可以通过 `PROMPT_DOCK_SIGNING_IDENTITY` 指定钥匙串里的签名身份。没有证书时会使用临时签名，每次更新后需要为新版本重新开启辅助功能权限。

运行发布打包脚本可生成供两种 Mac 架构使用的 `dist/futools-v<版本>-macOS-universal.zip`。

```sh
./scripts/package-release.sh
```

使用 macOS 命令行工具中的 Swift 编译器验证提示词库。

```sh
./scripts/test-store.sh
```
