# futools v1.5.1 动效审查

Gemini 从方案、文案和交互三个角度参与评审。采用了单行工具栏、短淡入、固定反馈位置和切页保留草稿的建议。侧栏与聊天窗口属于不同进程，位置由现有的 macOS 辅助功能接口跟踪。整体节奏沿用原生窗口和 SwiftUI 控件能共同使用的缓出曲线。 [Apple Human Interface Guidelines · Motion](https://developer.apple.com/design/human-interface-guidelines/motion)

## 按状态变化检查

| 状态变化 | 实现 |
| --- | --- |
| 出现、收起、快速重开 | 命令面板、精简面板、Copilot 和菜单栏 OCR 使用共同的入场节奏。非交互的退出约 100 ms，重开可取消待执行的关闭。需要把焦点交还聊天窗口时立即收起。 |
| 移动、变大、变小 | 宿主拖动和缩放时直接同步窗口坐标。选区拖动只重绘有变化的区域。拖入 OCR 时，接收区立即可用。 |
| 切页、选中、换内容 | 侧栏保持顶部位置，回复、资料和 Agent 使用约 180 ms 的入场淡入。旧编辑器立即退出。提示词列表切换选择时只重绘受影响的行。草稿和已展开的来源随会话保留。 |
| 按下、悬停、数量和图标改变 | 按压采用约 120 ms 的轻量反馈。计数、工具按钮和活动图标留出固定空间，减少变化时的布局跳动。 |
| 加载、完成、错误、重试 | 语音、优化、回复、资料保存、Agent、OCR 和密钥状态在操作附近反馈。可重试的 OCR 和 Agent 错误保留原输入。 |
| 深浅色、窄宽变化、减少动态效果 | 使用应用原有的两套色板。减少动态效果关闭自定义动画，加载时用静态沙漏。侧栏长资料标题可以截断，操作仍保留空间。 |

## 实测

| 场景 | 本机结果 |
| --- | --- |
| 侧栏显示 | 72 张离屏快照覆盖 300、320、380 pt、深浅主题和减少动态效果。快速切页检查中，只有当前页的原生编辑器可以接收输入。 |
| 窗口入场 | 60 Hz 合成窗口测试中，录到的画面变化间隔 P95 从 33.33 ms 降到 16.67 ms。等待再次唤出时，旧退出计时器未关掉新窗口。 |
| 长列表与预览 | 使用 1,500 条合成提示词和 2,400 字符的预览，按显示刷新节奏各执行 130 次滚动。画面变化间隔 P95 分别为 22.00 和 21.91 ms，两轮均无超过 33 ms 的间隔。捕捉到的画面变化约为每秒 57 次。 |
| 资料搜索 | 同一批 1,000 条合成资料、70 次查询中，耗时 P95 从 153.53 ms 降至 4.90 ms，返回数量校验一致。 |
| 拖框绘制 | 840 × 520 pt 的选区各测 375 帧。全量绘制 CPU 耗时 P95 从 2.33 ms 降至 1.30 ms，局部绘制从 0.42 ms 降至 0.30 ms，最终位图校验一致。 |

滚动数字来自 60 Hz 屏幕的窗口采样，实际刷新帧率仍需硬件级测量。300 pt 和 320 pt 是 macOS 窄布局模拟，未在 iOS 或 120 Hz 屏幕上验证。语音、OCR 和 Agent 界面状态使用合成数据及模拟响应检查。
